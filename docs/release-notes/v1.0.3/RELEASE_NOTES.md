# Release v1.0.3: Colour-coded folders

## Features

- Folders in the workspace can be given a colour. Right-click one, pick "Folder colour", and its icon takes that colour; "Default colour" puts it back. Eight colours, each picked to stay legible in both the light and the dark theme. A colour stays on the folder you set it on rather than spreading to everything inside it, and it follows the folder when you rename it

## Bug fixes

- The file dialog offered its "all files" option under a Polish name, left over from before the fork. It now follows the language you have chosen, on both the ordinary Open dialog and the one used when a file is already open in another window
